BƯỚC 3: TẠO PREDICT_LOCAL.PY
────────────────────────────────────────────────────────────────────────────────

Tạo file `ml_model/predict_local.py`:

```python
import xgboost as xgb
import pandas as pd
import os

class StockPredictorLocal:
    def __init__(self, model_path="models/best_model.json"):
        """Load model từ file local"""
        if not os.path.exists(model_path):
            raise FileNotFoundError(f"Model file not found: {model_path}")
        
        self.model = xgb.XGBClassifier()
        self.model.load_model(model_path)
        print(f"✅ Loaded model from {model_path}")
    
    def predict(self, features: pd.DataFrame):
        """Predict: 0=DOWN, 1=UP"""
        return self.model.predict(features)
    
    def predict_proba(self, features: pd.DataFrame):
        """Get probabilities: [prob_down, prob_up]"""
        return self.model.predict_proba(features)
```

from ml_model.predict_local import StockPredictorLocal  # Dùng local
import pandas as pd

# Load model khi start
predictor = StockPredictorLocal("models/best_model.json")

@app.post("/predict")
def predict(request: PredictRequest):
    features = pd.DataFrame([request.features])
    prediction = predictor.predict(features)
    proba = predictor.predict_proba(features)
    
    return {
        "prediction": int(prediction[0]),
        "confidence": float(proba[0][1]),

Q1: Option 1 vs Option 2- Chọn cái nào?
────────────────────────────────────────────────────────────────────────────────

A:  OPTION 1 (MLflow) nếu:
    • Có token
    • Cần auto-update
    • Production
    • Team nhiều người

    OPTION 2 (File) nếu:
    • Không có token
    • Test/demo ngắn hạn
    • Chạy offline
    • Chỉ 1 người dùng


Q2: Token có hết hạn không?
────────────────────────────────────────────────────────────────────────────────

A:  TÙY CHỌN khi tạo:
    • 90 days: An toàn, cần renew
    • No expiration: Tiện nhưng rủi ro nếu leak
    
    Nếu token expire:
    • BE sẽ báo lỗi "Token expired"
    • Xin token mới từ chủ workspace
    • Update DATABRICKS_TOKEN trong .env
    • Restart BE


Q3: Mỗi lần train model mới, BE phải làm gì?
────────────────────────────────────────────────────────────────────────────────

A:  OPTION 1: Chỉ cần RESTART BE!
    • MLOps train → Set alias production → Done
    • BE restart → Load model mới tự động
    • Không cần copy file, không cần code mới
    
    OPTION 2: Phải copy file lại
    • MLOps train → Export best_model.json
    • Gửi file cho BE
    • BE copy vào models/
    • BE restart


Q4: Model size bao nhiêu? Load nhanh không?
────────────────────────────────────────────────────────────────────────────────

A:  • Model size: 401 KB (nhỏ)
    • Option 1 load lần đầu: ~10 giây (download)
    • Option 2 load: <1 giây (file local)
    • Sau khi load: Predict <10ms (rất nhanh)


Q5: BE có cần quyền gì ngoài đọc model?
────────────────────────────────────────────────────────────────────────────────

A:  KHÔNG! BE chỉ cần:
    • READ model từ MLflow Registry
    • Không cần quyền workspace
    • Không cần quyền query data
    • Không thể train/sửa model
    → An toàn!


Q6: Có thể dùng nhiều môi trường (dev/staging/prod) không?
────────────────────────────────────────────────────────────────────────────────

A:  CÓ! Dùng alias:
    • Development: alias="staging"
    • Production: alias="production"
    • A/B Testing: alias="champion" vs "challenger"
    
    Code:
    ```python
    # Dev
    predictor = StockPredictor(alias="staging")
    
    # Prod
    predictor = StockPredictor(alias="production")
    ```


Q7: Rollback model nếu version mới có vấn đề?

    client = mlflow.tracking.MlflowClient()
